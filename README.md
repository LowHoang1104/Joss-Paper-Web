# VietMa

## Problem

Traditional joss paper products are often sold in large quantities and use materials that are not suitable for modern urban lifestyles. Customers may also find it inconvenient to choose and purchase appropriate products for different occasions.

## Solution

VietMa provides compact and convenient joss paper products designed for modern living. The website allows customers to explore products, choose suitable packages, and purchase them online.

The project focuses on providing a simple online shopping experience while promoting a more convenient and environmentally friendly approach to traditional joss paper products.

## Project Description

**VietMa** is an e-commerce website for selling compact joss paper products and related packages.

### Main Features

* Browse joss paper products.
* View product details.
* Browse available product packages.
* Online shopping and ordering.
* Customer information management.
* Responsive web interface.
* Integration with Supabase.
* Deploy automatically using GitHub Actions and GitHub Pages.
